# サウンド

日本語 · [English](sound.md)

競技場に音を付けられます。会場の種類に合った観客の音を「静か」から「大歓声」まで段階を選んで鳴らし、会場の屋根や広さに応じた響きで聞かせます。`@johnmorrisdotca/kyogijo-stadiums/sound` に入っていて、依存パッケージはありません。音はすべてブラウザーの中でWeb Audioを使って作ります。録音ファイルを持っている音は、ページ側からそのファイルを渡すこともできます。**読者がオンにするまでは鳴りません**。それまでは何も取得せず、何も作らず、何もデコードしません。

[デモ](https://johnmorrisdotca.github.io/kyogijo-stadiums/venues.html?sound=on&lang=ja)では、実在のアリーナのページ、「試してみる」の競技場の下、ページ冒頭のアリーナの上に「サウンド」ボタンがあります。

## 観客の音だけを鳴らす

```ts no-run
import { createKyogijoSound } from "@johnmorrisdotca/kyogijo-stadiums/sound";

const host = document.querySelector("#rink")!;
const sound = createKyogijoSound({ sport: "nhl", venue: { roof: "fixed", seats: 18000 }, view: "3d", level: "loud", host });
document.querySelector("#sound")!.addEventListener("click", () => sound.enable()); // ブラウザーは操作のあとでしか音を出せないため、ボタンの押下で呼ぶ
sound.setLevel("roar");
sound.setVolume(0.4);
sound.disable();
```

`createKyogijoSound(settings)` は `enable()` を呼ぶまで何も作りません。`enable()` はボタンの押下などの操作から呼びます（ブラウザーは操作のあとでしか音を出せません）。最初の `enable()` で、ページに1つだけのオーディオコンテキストを作り、`files` で渡された録音のうちその競技場で使うものを取得します。ページ内のすべてのサウンドが、このコンテキストを共有します。

| 設定 | 内容 |
| --- | --- |
| `sport` | 競技場（`nhl`、`soccer`、`judo` など）。サウンドセットのない競技場は音を出しません（`state().has` が false）。その場合、ページにはサウンドの操作を表示しません。 |
| `venue` | `{ roof, seats }`。屋根の種類（実在の会場のデータと同じ `open`、`canopy`、`cable`、`panels`、`fixed`、`dome`、`saddle`、`barrel`）と座席数です。省略すると会場の種類ごとの既定値を使います。 |
| `crowd` | 埋まっている座席の割合で、0から1まで（既定は1）。0は観客のいない建物で、館内の空気の音だけになり、盛り上がりの段階は選べません。 |
| `view` | `3d` は建物の中で聞く音、`2d` は真上から見た図で、中継のように観客が遠く、響きの少ない音になります。 |
| `level` | `quiet`、`murmur`、`engaged`（既定）、`loud`、`roar`。 |
| `volume` | 0から1まで（既定は0.6）。0は消音で、その間は何も鳴らさず、何も作りません。 |
| `files` | 名前ごとの録音（`murmur`、`applause`、`water`、またはほかのレイヤーの名前）。最初の `enable()` で取得し、聞こえる状態になって初めてデコードします。渡されなかった音はブラウザーの中で作ります。 |
| `host` | 競技場を描いている要素。画面の外に出ている間は音を止めます。 |
| `audio`、`fetch`、`doc` | テストのための、オーディオコンテキストを作る関数、fetch、document。 |

`setLevel`、`setVolume`、`setContext({ sport, venue, crowd, view })` で、鳴らしながら変えられます。観客の音はおよそ1秒かけて新しい段階に移り、競技場が変わればその会場の観客の音に切り替わります。`state()` は今の状態を返します。`has`、`on`、`audible`、`quiet`（鳴っていない理由：`no-sound`、`off`、`muted`、`hidden`、`out-of-sight`）、選んだ段階と実際に鳴っている段階（`heard`）、その競技場で選べる `levels`、取得したファイルです。`destroy()` で止め、リスナーも取り除きます。

## サウンドセットの一覧

競技場の音は、ページごとに書くのではなく、一覧から引きます。会場の種類ごとに観客の音（**ベッド**）があり、競技ごとにベッドと合図の音をまとめた**セット**があります。ページの操作はそのセットに従い、選べる段階だけを表示します。セットのない競技場には何も表示しません。

| ベッド | 屋内 | 残響 | 段階 | 競技 |
| --- | --- | --- | --- | --- |
| `arena` | はい | 2.2秒 | 5段階すべて | アイスホッケー、バスケットボール、スピードスケート、フィギュアスケート |
| `stadium` | いいえ | 0.7秒 | 5段階すべて | 各種フットボール、サッカー、ラグビー、オーストラリアンフットボール、ゲーリック・ゲームズ、ラクロス、フィールドホッケー |
| `ballpark` | いいえ | 0.6秒 | 5段階すべて | 野球、クリケット |
| `hall` | はい | 1.6秒 | 5段階すべて | ネット型・ラケット型の各競技とコート競技、ハンドボール、ネットボール、カーリング（3段階） |
| `pool` | はい | 2.6秒 | 5段階すべてと水の音 | 競泳、水球、飛込、アーティスティックスイミング |
| `dojo` | はい | 1.3秒 | 「静か」から「歓声」まで | 柔道、空手、剣道、道場。弓道は「静か」と「ざわめき」のみ |
| `ring` | はい | 1.8秒 | 5段階すべて | 相撲、総合格闘技、ボクシング、レスリング、プロレス |
| `track` | いいえ | 0.8秒 | 5段階すべて | 陸上競技 |

サーキットにはまだセットがないため、サウンドの操作は表示しません。

```ts
import { SOUND_BEDS, soundLevelsOf, soundSetOf } from "@johnmorrisdotca/kyogijo-stadiums/sound";

console.log(soundSetOf("nhl")?.bed, SOUND_BEDS.arena.indoor, soundLevelsOf("kyudo").join());
console.log(soundSetOf("circuit"));
// arena true quiet,murmur
// undefined
```

`SOUND_BEDS`、`SOUND_SETS`、`SOUND_OF_SPORT` が一覧です。パッケージが描くすべての競技場にセットがあることを、テストで確かめています。

## 会場の響きと観客

音は競技場だけでなく、そのときの条件（コンテキスト）によっても変わります。`soundRoom(context)` は、会場がどれだけ囲まれているか（屋根）、どれだけ長く響くか（囲まれているほど、建物が大きいほど長くなります）、残響の量、そして観客の大きさを返します。観客の大きさは、座席数に埋まっている割合を掛けた人数から求めます。観客の音は人数に比例して大きくなるわけではないため、人数よりゆるやかに増える尺度を使っています。`soundMix(context, level)` は、それに各段階での各レイヤーの音量を加えて返します。

```ts
import { soundMix, soundRoom } from "@johnmorrisdotca/kyogijo-stadiums/sound";

const arena = soundRoom({ sport: "nhl", venue: { roof: "fixed", seats: 18000 } })!;
const open = soundRoom({ sport: "soccer", venue: { roof: "open", seats: 50000 } })!;
console.log(arena.decay > open.decay, arena.wet > open.wet, soundRoom({ sport: "nhl", crowd: 0 })!.crowd);
const flat = soundRoom({ sport: "nhl", venue: { roof: "fixed", seats: 18000 }, view: "2d" })!;
console.log(flat.wet < arena.wet, soundMix({ sport: "judo" }, "roar")!.level);
// true true 0
// true loud
```

ベッドは4つのループを上げ下げして作ります。館内の**空気**、人々の**話し声**、**拍手**、観客全体の**声**です（プールには**水の音**が加わります）。静かな館内はほとんどが空気の音で、大歓声はほとんどが人の声です。その競技にない段階を選ぶと、いちばん近い段階になります。道場で「大歓声」を選ぶと「歓声」になります。

## かかる負荷

- **既定ではオフです。** `enable()` の前には何も取得せず、何も作らず、何もデコードしません。すべての設定を変えても、オーディオコンテキストが作られず、ファイルも要求されないことをテストで確かめています。
- **オーディオコンテキストはページに1つです。** ページ内のすべてのサウンドが共有し、どれも聞こえていないときは一時停止します。
- **聞こえていない間は、鳴らすこともデコードすることもしません。** オフのとき、音量が0のとき、ページが非表示のとき、競技場が画面の外にあるとき（`host` を `IntersectionObserver` で見ています）は、ベッドのループを止めて音の経路を取り除きます。その間に取得した録音は、聞こえる状態になってからデコードします。タイマーは動かず、アニメーションフレームも要求しません。
- **ベッドの音量を動かすのは、段階か設定が変わったときだけです。**
- **小さく作っています。** ブラウザーで作るループは6秒で、初めて聞こえるときにシードから一度だけ書き出します。デモの録音は短いループと単発の音で、モノラルのOpus（Opusをデコードできないブラウザー向けにAAC）です。どの競技でも読み込む量はOpusで110 kB未満、AACで190 kB未満で、すべての競技のセットが160 kBと250 kB以内に収まることをテストで確かめています。録音はnpmパッケージには含めません。

## 録音

パッケージには録音を含めません。音はブラウザーの中で作ります（観客の声は、フィルターを通したノイズの音量をゆっくり変えて作ります）。デモは自前の録音を使います。どれもCC0かパブリックドメインで、出典、作者、ライセンスを[サウンドのクレジット](./sound-credits.md)に載せています。`pnpm sounds:fetch` と `pnpm sounds` で作り、音量をそろえ、低域を切り、ループのつなぎ目を消しています。自分のページでも、同じように `files` に名前で録音を渡せます。ただし、チームのゴールソング、ホーン、チャントは使わないでください。ライセンスで禁じられた録音も使えません。

## 読者への配慮

- 音が勝手に鳴り始めることはありません。アドレスに `sound=on` がある場合（デモ）も、読者がページのどこかを最初に押したときにオンになります。
- 操作には英語と日本語の名前（`SOUND_WORDS`）が付いたボタン、音量のスライダーがあり、段階はボタンを横に並べています。折りたたんで開くリストにはしていません。動きを減らす設定にしている読者にも音は聞こえます。この設定は動くものに関するものだからです。
- テストでは音を鳴らしません。オーディオコンテキストの代わりを使い、ブラウザーのテストでは実際の音の経路をメモリー上に書き出して（`OfflineAudioContext`）、無音でも音割れでもなく、段階ごとに大きくなることを確かめています。
