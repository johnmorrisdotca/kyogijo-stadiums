# 球場

日本語 · [English](ballparks.md)

球場の名前に関する取り決めの、日本語の説明です。球場の距離、壁、特徴、シーズンごとの描き分け、コードの例は[英語版](ballparks.md)にあります。

## 名前

球場には、人びとが使う名前と、それ以外に呼ばれるすべての名前があり、どれにも、その名前を読み取った出典が付いています。これは日本の球場にも、アメリカやカナダの球場にも同じように当てはまります。

- `name` は**英語の通称**で、英語のスポーツメディアが使う名前です。企業名が付いていて、人びとがその名で呼ぶ場合は、企業名を採ります。引用した記事の題名と同じとはかぎらず、その題名は別名（alias）として残します。
- `nameJa` は**日本語の通称**で、日本のメディアが使う名前です（甲子園球場、神宮球場、マツダスタジアムなど）。アメリカやカナダの球場では、日本語版の記事の題名です。`readingJa` は、漢字を含む名前の読み（かな）です（たとえば、こうしえんきゅうじょう）。`localName` と `localLanguage` はその土地の言語での名前で、日本の球場は `ja`、モントリオールの二つの球場は `fr` です。英語圏の球場にはありません。
- `aliases` はそれ以外の名前で、`{ name, lang, kind, from?, to?, source?, revision? }` の形をしています。`kind` は次のいずれかです。`wikipedia`（引用した記事の題名。英語版でも日本語版でも、`revision` を付けるので、出典は一つも失われません）、`official`（所有者や運営者が呼ぶ名前で、通称と違うもの）、`sponsor`（命名権による名前）、`former`（以前の名前）、`nickname`（略称や、人びとが使う呼び名）。`from` と `to` は出典が示す年で、`source` は名前を読み取った場所（記事とその版、または Wikidata の項目とプロパティ）を示します。
- `parkByName(name)`（と、名前に当てはまる球場をすべて、近い順に返す `parksByName`）は、これらのどの名前でも、英語でも日本語でも球場を探します。比較では、大文字小文字、アクセント、空白と記号、全角と半角、ひらがなとカタカナ、長音符の違いを区別しません。
- 図のタイトルは、その言語での通称です。正式名称が別にある球場では、説明文にその言語で正式名称を書きます。`parkOfficialName(park, language, year)` が、その名前を返します。
